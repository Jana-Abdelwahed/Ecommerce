# 🛍️ E-Commerce App

A full-featured cross-platform e-commerce application built with Flutter. The app features a dynamic product catalog, category browsing, custom item components, and responsive layouts tailored for mobile devices.

## ✨ Features

* **Home Dashboard:** Auto-scrolling promotion banners, top category grid, and horizontal product list highlights.
* **Product Catalog:** Grid view displaying available items with custom spacing, responsive sizing, and fallback assets.
* **Reusable Product Cards:** Standardized card widget featuring image caching fallbacks, discount badge tags, rating indicators, dynamic pricing, and floating favorite buttons.
* **Localization & Dynamic Themes:** Built with internationalization support and standardized design constants.
* **Navigation:** Smooth route navigation across primary screens, including detailed product views.

---

## 🛠️ Tech Stack

* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* **Screen Responsiveness:** `flutter_screenutil`
* **UI Components & Icons:** Material Design & Custom Vectors
* **State Management:** Provider / Clean Architecture Patterns
